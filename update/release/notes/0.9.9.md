# BlockHelm Launcher 0.9.9

## 新增功能

### 启动器字体更换
- 支持预设字体选择（微软雅黑、黑体、宋体、楷体等13种常用字体）
- 支持自定义字体模式，可输入或选择系统已安装的字体
- 设置页面包含字体预览区域，实时显示字体效果
- 支持简体中文、繁体中文、English、日本語

## 使用方法

1. 打开启动器设置
2. 进入「外观设置」
3. 找到「字体设置」区域
4. 选择预设字体或开启「自定义字体」模式

## 注意事项

- 需要 .NET 8 Desktop Runtime
- 部分字体可能需要在系统中安装才能使用

## 完整变更日志

- 新增 `LauncherFontFamily` 设置属性
- 新增 `ApplyFont()` 方法到 `IThemeService`
- 新增 `SettingsFontFamilyOption` 模型类
- 新增字体选择 UI 和预览区域
- 新增系统字体列表支持
- 新增自定义字体输入模式
